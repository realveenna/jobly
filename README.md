# Jobly

 Jobly is a web-based job search and wage calculator designed to help users explore career opportunities and understand different wage rates.

 The website uses the **LMI for All API** to retrieve job vacancy and occupational information.

 ## Features

 ### Job Search

 - Search for jobs by job title and location
- Display recent job vacancies
- View job location, company and description
- Open application links for individual vacancies
- View related job descriptions
- Expand and collapse job results

 ### Wage Calculator

 - Enter a job title and wage
- Choose between hourly, weekly, monthly or yearly pay
- Enter the number of hours worked per week
- Automatically calculate equivalent hourly, weekly, monthly and yearly wages
- Input validation, including a maximum of 168 working hours per week

 ## API

 Jobly uses the **LMI for All API** to retrieve job vacancy and occupational data.

 The project uses:

 - Vacancy Search API
- SOC (Standard Occupational Classification) Search API

 API requests are made using JavaScript's `fetch()` function.
